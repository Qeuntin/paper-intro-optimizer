# 五类检查与判定标准

每条给出**判定依据**与**适用边界**。边界的重要性和判定本身一样：规则用的是判断，不是套模板。

---

## A 证据与表述的匹配

| 编号 | 检查项 | 判定依据 | 边界 |
|---|---|---|---|
| A1 | 每篇文献能说出支持哪一项论断 | 能在台账“支持关系”栏写出：引言拟写的句子 ↔ 证据原文 ↔ 支持程度 | 支持的可以是背景、机制、测量方法、制度条件，不限于结论 |
| A2 ★ | 表述强度 ≤ 证据强度 | 只有摘要时，不写需要全文才能核实的变量定义、效应大小、模型细节 | 经典理论、标准、政策文件无摘要也可引用，须标明来源、阅读程度与摘要状态（原文无摘要） |
| A3 ★ | 不把他人因变量的结论当作本文因变量的证据 | 逐句核对：这句话讲的行为对象，是否就是本文的因变量 | 因变量不同的研究可用于解释条件、机制、方法对照 |
| A4 | 数值、口径、方法比较、因果表述须查全文 | 出现具体数字、变量定义、“优于/导致/使得”等词时，回原文相应位置核对 | 概括性结论（“有显著影响”）摘要可支撑 |
| A5 ★ | 单城市/单群体研究不被写成普遍规律 | 结论适用范围相关处标地点；同时记录人群、时期、制度条件 | 与适用范围无关的引用（如方法类）不必强行加地名 |
| A6 | 区分方法结论与实质结论 | “模型精度 91.62%”“优于多元 Logit”是方法结论；“什么因素影响什么行为”才是实质结论 | 方法结论可放在“研究深度”的论述中，但不能当作行为发现 |
| A7 | 编号与文献一一对应 | 每个 `[n]` 在文献表存在，内容对应 | — |
| A8 ★ | 区分“引用综述自身结论”与“通过综述转引原研究” | 引系统综述/元分析的综合结论 → 直接引该综述；转述其中某篇未读原研究的发现 → 注明转引关系，不声称已核查原研究 | 综述或元分析**自身的综合结论可直接引用**；其证据质量按检索范围、纳入标准、偏倚评估与综合方法判断，**不因属二次研究而自动降级**；而二次转述的核查状态不得高于已读来源 |
| A9 ★ | 不臆断“无人研究” | 只有摘要时，不写“该问题尚无研究”；检索不充分时写“本次核查文献中较少涉及” | 做过系统检索并能说明检索式时，才可用“未见报道”类表述 |
| A10 | 作者名与题名双核 | 检索池中同名作者可能有多篇，须比对题名 | — |

## B 论证逻辑

| 编号 | 检查项 | 判定依据 | 边界 |
|---|---|---|---|
| B1 ★ | 并列项同维度 | 两个分句在说同一维度：都是因变量、都是分析单元、都是方法 | 维度不同即拆句，不硬凑同一个状语 |
| B2 ★ | 并列项须有共同点 | 能回答“它们共同是什么”，并写出来（如“都只给一个综合水平”） | 共同点也可以是否定式的（“都没把 X 与 Y 分开”） |
| B3 | 论证链可追 | 每段能还原为“因为 A，所以 B”，连接词显化（因而/正是/因此） | 链长可 2–4 环，不要求固定环数 |
| B4 ★ | 段首句罩得住分论点 | 逐条问“这句话管得住它吗”；管不住就重写首句 | 分论点数量按实际证据定，不必凑三 |
| B5 | 数量词与实情一致 | 写“三处”“两条线索”时回头数一遍 | 数量不确定时改用不含数目字的表述 |
| B6 | 段间衔接 | 前段末与后段首构成“问题—回应”关系 | 不靠“综上所述”“基于此”这类过渡套话 |
| B7 ★ | 缺口与方案覆盖完整、对应明确 | 每项缺口能在方案与贡献部分找到回应，每项回应能指回缺口（不限定在第几段） | 允许一项缺口由多个分析回应，也允许一个方法回应多项缺口；多出的贡献若正文有实际分析，可单列为增量贡献 |
| B8 ★ | 先承接后转折 | 缺口段先写前人把解释推进到哪一层，再转折 | 承接要具体（“从个体特征扩展到家庭属性与建成环境”），不是“已有研究意义重大” |

## C 术语与概念

| 编号 | 检查项 | 判定依据 | 边界 |
|---|---|---|---|
| C1 ★ | 调查工具、题项、指标、量表四者分清 | 问卷＝调查工具；题项＝问卷里的问法；指标＝由题项算出的量；量表＝多题组合的测量方式。按原文实际操作表述： “通过问卷获取出行次数”“根据题项构建指标”“使用某量表测量” | **不得自行把“问卷”改称“量表”**——问卷可直接记录次数与数量，也可能只有单题、并不构成量表 |
| C2 ★ | 分析单元、观测记录、聚类单元三者分清 | 分析单元＝研究对象（家庭/个人）；观测记录＝数据行（一次出行/一户一行）；聚类单元＝标准误归并单位。原句用哪个词，须与三者之一对应 | 家庭完全可以是一户一行（观测记录），也可以是聚类单位；不能一概说“以家庭为单位只能修饰标准误” |
| C3 ★ | 系数 ≠ 因变量水平 | 回归系数衡量自变量效应，不是因变量本身 | 报告边际效应时须说明“对…的影响” |
| C4 | 检验 ≠ 估计 | 模型是估计；“检验”指假设检验（Wald/LR） | “用模型检验关联是否成立”可接受 |
| C5 ★ | x / y 须点明 | 写“某变量未被用作解释变量”时，说明解释的是什么 | — |
| C6 | 术语首现可懂 | 引言避免未定义术语（潜变量、聚类稳健、条件份额）；必须用时补一句白话 | 读者群为专业同行时可适度放宽 |
| C7 | 全文用词统一 | 同一概念不用两种叫法（个体/个人、使用强度/使用水平） | — |
| C8 | 缩写首现给全称 | 期刊通用要求（ICLV、GWR 等） | — |

## D 结构

| 编号 | 检查项 | 判定依据 | 边界 |
|---|---|---|---|
| D1 ★ | 每句可独立读懂 | 遮住段落小标题逐句读，仍能知道讲什么工具、什么对象 | 同一句群内可用指代，但指代对象须在前一句明确出现 |
| D2 | 总括句位置按需选择 | 归纳（证据在前、判断在后）与演绎（判断在前、证据在后）都可用于学术写作 | 段首先给判断、随后举证同样成立；同一篇内保持一致即可，不设统一模板 |
| D3 ★ | 段首不空转 | 避免只有分类不含内容的引导语（“测量上”“单元上”），改为直接说问题形态 | 有明确并列内容时，“就 X 而言”可用 |
| D4 | 段末有力 | 段末句是判断或落点，不是描述 | 末段可收在贡献上，不必都收在否定句 |
| D5 | 四项功能可辨认 | 背景/前人/缺口/方案四项能指认，允许按篇幅合段或拆段 | 不要求一段只承担一种功能 |
| D6 ★ | 不重复 | 同一信息不在两段各说一遍 | 关键限制在方法与结论各出现一次属正常 |

## F 编号与可追溯

| 编号 | 检查项 | 判定依据 | 边界 |
|---|---|---|---|
| F1 | 首现严格递增 | 1 → 2 → 3……；组合引用 `[2-3]` 视为一次首现 | 仅在全篇编号授权时维护 |
| F2 ★ | 涉及共享参考文献表须核查全篇编号 | 引言增删文献会改变正文后续编号（如引言由两篇变三篇，正文原 `[3]` 需顺延）；仅在确认不影响正文编号、或已获全篇调整授权时输出正式编号 | 临时编号 `[I1]…[In]` 用于独立工作稿；替换进原稿前须统一，不能视为交付完成 |
| F3 ★ | 合并引用的支持检验 | 范围内每篇都支持该论断；结论方向、适用条件、贡献有重要差异时分别叙述 | 方法不同但结论一致可以合并 |
| F4 | 回指不重复定义 | 缺口段回指前文文献时只引编号，不复述结论 | — |
| F5 ★ | 三文件编号一致 | 引言、核查表、摘要汇总的编号与顺序对应，共用一张映射表 | — |

## 交付前最后一眼

- [ ] **完整核查须覆盖全部“论断—文献”对应关系**；完成后至多抽查 3 条作追加复核（少于 3 条则全查）；证据不足项保留“待核”状态，不随核查表标为完成
- [ ] 每条引用都能说出“它支持哪一句论断”
- [ ] 分论点与首句承诺相符（数量可少，不可不符）
- [ ] 缺口四项链走通；有无“因为没找到就说没人做”
- [ ] 每项贡献在正文找得到对应分析
- [ ] 三份文件编号交叉核对；临时编号是否标注
