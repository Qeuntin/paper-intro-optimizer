# 语体润色（内置规则）

本文件把 `academic-language-editing` 的规则并入本技能，使润色环节不依赖外部技能即可执行。原文规则据该技能改写，未改变其判定标准；第四部分为引言场景的专用边界。

**来源与同步**：规则取自 `academic-language-editing` 技能，2026-10-21 同步。仅同步判定标准与工作流（第二、三部分），不同步其触发词与技能描述。原技能更新时，只替换第二、三部分；第四部分（引言场景边界）为本技能自有，不随原技能变动。

## 一、目标

改进语言，不改研究。作者的立场、问题、范围、方法、数据、结果、结论、引用与确定性程度，全部保持原样。

## 二、修改规则

1. **保真**：每一个数字、百分比、样本量、日期、时段、单位、公式、图表编号、参考文献编号与技术术语，均须保留；不重算，不静默统一口径。
2. **限定词**：保留“可能”“或许”“相关”“提示”“支持”等；不得把相关写成因果，把证据写成证明。
3. **不新增**：不补事实、机制、例子、参考文献、局限或解释。
4. **最小改动**：准确清楚的句子不动；只做解决真实语言问题的最小修改。
5. **语体**：保持正式、克制的学术书面语；删空话、重复结论、填充语、机械排比、指代不明与多余过渡；不制造生硬表达。
6. **保留必要的句法**：被动结构、术语定义、数据陈述与带引用的句子保持原样，除非确有歧义或语法错误。
7. **证据缺口当作者问题**：标“待作者核对”，写明缺哪个事实或来源；不为句子通顺而猜测。
8. **只求自然与可读**：不承诺过审，不以降低 AI 检测率为目标，不以检测分数作为质量依据。

## 三、工作流

1. **定权威文本**：版本冲突时以作者指定的版本为准；未获授权不改动源文件。
2. **通读并只挑需要改的句子**，按实际问题的类别标注：空话或空泛措辞、重复、模板腔、衔接不清、长句歧义、术语前后不一、论断超出所述证据、需作者确认的事实。
3. **逐条给三样**：原句（照录）、修改建议（完整替换句，或“保留原句”）、修改理由（具体的清晰度、语法、准确性或语体问题）；另附“需作者核对项”，无则写“无”。
4. **给完整改后段**：未改的句子原样保留；长文按原段序组织，不静默省略。
5. **保真复核**：逐项对照数量及其顺序、范围、方法、术语、引用归属、论断强度；列出未决的作者核对项。不宣称润色可保证录用。

**交付格式**：诊断（只列真有问题的句子）→ 逐条原句/建议/理由/待核 → 完整改后段 → 保真清单（数据与方法、强度与范围、新增事实或引用、未决待核、术语与编号一致性）。

## 四、引言场景的边界

### 何时进入

| 情形 | 是否进入 |
|---|---|
| 作者要求“润色”“语言把把关”“读起来不顺” | 是 |
| 初稿刚写完、论证未定 | 否——先做论证检查，否则白做 |
| 只问某一句通不通 | 否——直接回答，不启动流程 |
| 定稿后投稿前最后一次语言检查 | 是 |

顺序不可颠倒：**先论证，后语体**。润色不能替代论证检查，也不能以“更顺”为由改动引用归属。

### 交接输入

1. 权威文本（文件名 + 日期）；2. 术语表（本文固定用法）；3. 引用编号表（`[n]` 与文献对应）；4. 字数口径（当前字数、上限、是否已超限）。

### 可改与不可改

| 可改（语言问题） | 不可改（论证与证据） |
|---|---|
| 空话、套话、无信息的过渡句 | 数字、百分比、样本量、时期、单位 |
| 重复结论、同一意思说两遍 | 引用编号、引用归属、文献与论断的对应 |
| 机械排比（连续同动词、同句式） | 术语（换词会改变概念边界） |
| 指代不明（“前者”“该现象”指代不清） | 限定词强度（“可能”“相关”不得升为“导致”“证明”） |
| 长句歧义、一句塞三层意思 | 研究范围（城市、人群、时期、口径） |
| 同一概念两种叫法 | 论证顺序与段落归属（结构调整回主流程） |
| 语体不统一（口语与书面语混用） | 事实、机制、例子、局限——不得新增 |

### 五条硬边界

1. **不增字**：润色默认不增加字数；某处必须增字才能说清时，报告增量并从同段回缩等量文字。
2. **不改编号**：出现“这句该换一篇文献”的判断，登记为待作者核对，回主流程处置。
3. **不改强度**：把“相关”写成“影响”、把“提示”写成“表明”、删掉“样本内”，都属改变结论。
4. **不改术语**：术语只在原术语明显错误时提出替换，并须给出理由、列为待作者确认项。
5. **回跑检查**：润色后重跑论证检查（尤其证据匹配与编号）。润色最常见的隐性破坏是量纲与限定词——数字没动，主语换了、范围删了，意思就变了。

### 与论证检查冲突时

| 冲突 | 判定 |
|---|---|
| 润色认为“太绕”，但改写会动引用归属 | 保留原句，登记待核 |
| 润色建议删“冗余”限定词，而该限定词是证据边界 | 保留限定词 |
| 润色建议合并两句，合并后跨两个论证层次 | 不合并 |
| 润色建议改书面，而原句是刻意通俗 | 按作者语体要求；未明确时用学术书面语，且术语须落到所指 |

一句话：**润色只能让已经成立的话更好读，不能让不成立的话读起来成立。**
